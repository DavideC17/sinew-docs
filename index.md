# Sinew documentation

Sinew is a Shopify theme for activewear, sports nutrition and training brands. It pairs bold, editorial layouts with the product details athletes look for: fit, fabric, sizes and color swatches.

This guide explains every setting of the theme, page by page. Everything described here is done in the theme editor, with no code.

## Where to start

- New to Sinew? Read [Getting started](getting-started.md) first: it covers installing the theme, the theme editor and the setup order that saves the most time.
- Looking for a setting? Use the search at the top of the page, or open the page for the part of your store you are working on.
- Something not working as described? Check the [FAQ](faq.md), then [contact support](support.md).

{: .warning }
Duplicate your theme before you edit its code. In your Shopify admin, go to **Online Store > Themes**, open the **...** menu next to Sinew and choose **Duplicate**. Code edits are not covered by support and are not carried over when you update the theme.
