# Header and footer
{: .no_toc }

The header and footer show on every page. In the theme editor they are listed in the **Header** and **Footer** groups of the sidebar, and changes made there apply to the whole store.

1. TOC
{:toc}

## Announcement bar

A thin bar above the header for short messages, such as shipping offers or a new collection.

- Add up to 10 **Announcement** blocks, each with a text and an optional link.
- **Rotate announcements automatically** changes the message every 3 to 10 seconds. Visitors can pause the rotation, and it never runs for visitors who turn on reduced motion.

## Header

| Setting | What it does |
| --- | --- |
| Logo position | Left or Center. |
| Menu | The main menu, from **Content > Menus** in your Shopify admin. |
| Menu style | **Dropdown** opens a list under each menu item. **Mega menu** opens a full-width panel with all the links of the menu item, and can show promo images. |
| Customer account menu | Links shown in the account menu, when customer accounts are turned on. |
| Sticky header | **None**, **Always** (stays at the top while scrolling), or **On scroll up** (hides while scrolling down and returns when scrolling up). |
| Enable transparent header on the home page | The header sits over the first section of the home page. Works best when the first section is a full-width image, video or colored section. |
| Transparent header color scheme | Colors of the header while it is transparent. Pick a scheme whose text is readable over your first image. |
| Show search | Shows the search icon. |
| Show country/region selector | Shows when you sell in more than one country or region. Manage countries in **Settings > Markets**. |
| Show language selector | Shows when your store has more than one published language. Manage languages in **Settings > Languages**. |

### Building the menu

In your Shopify admin, go to **Content > Menus**. Links nested under another link become its drop-down. With **Mega menu**, a menu item's nested links become columns, and links nested one more level become the links of each column.

### Menu promos

With **Mega menu**, you can show promo images next to the links of a menu item, for example a new collection under "Women". One or two promos per menu item work best; the header holds up to 8 promos in all.

1. In the theme editor, choose the **Header** section, then **Add block > Menu promo**.
2. In **Menu item**, enter the title of the main menu link the promo belongs to, exactly as it shows in the menu, for example `Women`. The menu item must have nested links.
3. Add an image, a subheading, a heading and a link. The whole promo is clickable.

While you edit a promo, the theme editor opens its menu so you can see it.

## Footer

The footer is built with blocks, arranged in columns (**Columns on desktop**: 1 to 5). Useful blocks:

| Block | What it shows |
| --- | --- |
| Menu | A heading and the links of a menu, for example "Help" or "Company". |
| Newsletter | A heading, text and an email signup field. Signups are saved as customers in your Shopify admin, subscribed to email marketing. |
| Social media icons | Icons linking to the accounts set in **Theme settings > Social media**. |
| Text, Heading, Image, Button | Any other content, for example your brand story. |
| Group | Puts several blocks together in one column. |

The **Bottom bar** settings show the country/region and language selectors, the **Follow on Shop** button (when your store can use Shop Pay), and payment icons for the payment methods your store accepts.

The copyright line shows the current year and your store name.

## Newsletter popup

A signup dialog that opens once per visitor, after a delay. Add it from the **Footer** group: **Add section > Newsletter popup**.

| Setting | What it does |
| --- | --- |
| Image, Subheading, Heading, Text, Button label | The content of the popup. |
| Delay | 3 to 60 seconds after the page loads. |
| Show again after | 1 to 90 days: how long the popup stays hidden after a visitor closes it. |

The popup never opens over another open dialog, such as the cart drawer. In the theme editor it opens only when you select the section, so it doesn't get in the way while you edit other sections.
