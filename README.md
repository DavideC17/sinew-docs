# Sinew documentation

Source of the documentation site for Sinew, a Shopify theme by Davide Curto: https://davidec17.github.io/sinew-docs/

The site is built by GitHub Pages with Jekyll and the [Just the Docs](https://just-the-docs.com) theme (`remote_theme` in `_config.yml`). Every page is a Markdown file; the front matter sets its title and its place in the navigation (`nav_order`, `parent`).
