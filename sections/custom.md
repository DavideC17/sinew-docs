# Custom sections

## Custom section

A flexible section you fill with any blocks. In **Add section**, it is offered in several ready-made versions that you can change freely:

- **Custom section**: empty, to build your own layout.
- **Image with text**: an image next to a heading, text and button.
- **Columns**: three columns of heading and text, for example your brand values. Add an image or icon block to each column if you like.
- **Rich text**: a subheading, heading, text and button.
- **Newsletter**: a heading, text and email signup field.
- **Icons with text**: a row of icons with short texts, for example "Free shipping", "30-day returns".

| Setting | What it does |
| --- | --- |
| Content width | Page width, or Full width. |
| Layout direction | Horizontal (blocks side by side) or Vertical (blocks stacked). |
| Stack on mobile | Stacks horizontal blocks on small screens. |
| Horizontal alignment, Vertical alignment | How blocks line up. |
| Spacing | 0 to 100 px between blocks. |
| Minimum height | Adapt to content, Small, Medium, Large or Full screen. |
| Background image, Overlay opacity | An optional image behind the content. |

## Theme blocks

These blocks can be added to Custom section, Hero, the footer and other sections that accept blocks:

| Block | What it does |
| --- | --- |
| Group | Holds other blocks, in a row or a column, with its own spacing, padding and optional color scheme. Use groups to build columns and cards. |
| Heading | A heading with six sizes. **Heading level** (H1 to H6) sets its place in the page outline used by search engines and screen readers: use one H1 per page. |
| Text | Rich text in four styles: Body, Large, Small or Subheading. |
| Button | Solid, Outline or Text link, optionally full width or opening in a new tab. |
| Image | An image with an optional link, ratio, width and corner radius. |
| Icon | One of 16 icons, such as truck, return arrow, leaf or dumbbell, optionally on a round background. |
| Video | A YouTube, Vimeo or uploaded video with a cover image. |
| Menu | A heading and the links of a menu. |
| Newsletter | An email signup form. |
| Social media icons | Links to your social media accounts. |
| Payment icons | The payment methods your store accepts. |
| Follow on Shop | Lets customers follow your store in the Shop app. |
| Spacer | Empty space, with separate heights for desktop and mobile. |
| Custom Liquid | Code you add yourself. See below. |

Sections that accept blocks also accept **app blocks** from apps you install.

## Custom Liquid

The **Custom Liquid** section and block show code you add yourself, for example an embed code from a service you use or a snippet from an app's instructions. They are available on every page.

{: .warning }
Code added here is not covered by support. Duplicate your theme first (**Online Store > Themes > ... > Duplicate**), test the code on the copy, and only then add it to your live theme.
