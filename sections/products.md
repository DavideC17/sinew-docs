# Products and collections
{: .no_toc }

1. TOC
{:toc}

## Featured products

Products from one collection, as a grid or a carousel.

| Setting | What it does |
| --- | --- |
| Subheading, Heading, Heading size | The title of the section. |
| Collection | The collection to show. |
| Products to show | 2 to 16. |
| Layout | Grid or Carousel. |
| Columns on desktop | 2 to 5. |
| Show view all link | Links to the collection. |

The cards follow the [Product cards](../theme-settings.md#product-cards) theme settings.

## Product tabs

Several collections in one section, with a tab for each, for example "Bestsellers", "New in" and "Sale".

| Setting | What it does |
| --- | --- |
| Heading, Heading size | The title of the section. |
| Products per tab | 2 to 16. |
| Columns on desktop | 2 to 5. |

**Tab blocks** (up to 5): a collection and an optional tab label. Without a label, the collection title is used.

## Featured product

One product with its photos, price, options and add to cart button, anywhere in your store. Its blocks are the same as on the product page: see [Product page](../product-page.md).

| Setting | What it does |
| --- | --- |
| Product | The product to show. |
| Media position | Left or Right. |

## Product in 3D

A product's 3D model, which visitors can turn and zoom, next to a heading, text and button.

| Setting | What it does |
| --- | --- |
| Product | A product with a 3D model in its media. Without one, its photo shows. See [3D models](../product-page.md#3d-models). |
| Subheading, Heading, Text | The text of the section. |
| Button label, Button link | Leave the link empty to link to the product. |
| Rotate automatically | The model turns slowly on its own. Visitors can still turn and zoom it. |
| Media position | Left, Right or Top. |

When the product has color swatches, visitors can switch colors, and each color can have its own 3D model.

## Feature tour

A product image or 3D model in the center, with the features of the product around it. With a 3D model, the model turns as visitors scroll.

| Setting | What it does |
| --- | --- |
| Subheading, Heading | The title of the section. |
| Button label, Button link | Leave the link empty to link to the product of the 3D model. |
| Image | Use a PNG with a transparent background, for example a product photo without its background. |
| 3D model | A product with a 3D model. It takes the place of the image. |

**Feature blocks** (up to 8): a title and a text each, for example "Breathable mesh" and a sentence about it.

## Collection list

A grid or carousel of collection cards.

| Setting | What it does |
| --- | --- |
| Subheading, Heading, Heading size | The title of the section. |
| Layout | Grid or Carousel. |
| Columns on desktop | 2 to 5. |
| Image ratio | Square, Portrait or Landscape. |
| Card style | Text over image, or Text below image. |
| Show product count | Shows the number of products in each collection. |
| Show view all link | Links to your collections page. |

**Collection blocks** (up to 12): one collection each. The card uses the collection's image, set in your Shopify admin under **Products > Collections**.

## Collection links

A list of large collection names. When visitors point at a name, its image shows next to the list.

| Setting | What it does |
| --- | --- |
| Subheading, Heading | The title of the section. |
| Image position | Left or Right. |
| Show numbers | Numbers the collections (01, 02, ...). |
| Show product count | Shows the number of products in each collection. |

**Collection blocks** (up to 8): a collection, with an optional title and image that replace the collection's own.

## Recently viewed

The products the visitor viewed most recently, newest first.

| Setting | What it does |
| --- | --- |
| Heading | The title of the section. |
| Products to show | 2 to 12. |
| Columns on desktop | 2 to 6. |

The list is kept in the visitor's browser only: no cookie is set and nothing is sent to a server. On a product page, the current product is left out. The section stays hidden for visitors who haven't viewed any product yet. In the theme editor it shows example cards so you can style it.
