# Collections and search
{: .no_toc }

To edit the collection page, open the theme editor and choose **Collections > Default collection** in the page selector at the top.

1. TOC
{:toc}

## Collection banner

The top of the collection page, with the collection's title, description and image. Set the image and description in your Shopify admin, under **Products > Collections**.

| Setting | What it does |
| --- | --- |
| Layout | Text over image, Image next to text, or Text only. |
| Heading size | Display, Extra large or Large. |
| Show collection image | Shows the collection's image. |
| Show collection description | Shows the description. |
| Show product count | Shows the number of products in the collection. |
| Overlay opacity | 0 to 90 %. Tints the image so the text stays readable over it. |

## Product grid

| Setting | What it does |
| --- | --- |
| Products per page | 8 to 48. |
| Columns on desktop | 2 to 5. |
| Columns on mobile | 1 or 2. |
| Grid spacing | Compact, Normal or Spacious. |
| Pagination | Page numbers, Load more button, or Infinite scroll. See [Pagination](#pagination). |
| Enable filtering | Shows the filters. See [Filters](#filters). |
| Filter layout | **Sidebar** shows the filters next to the products on desktop. **Drawer** opens them from a button. On mobile, filters always open in a drawer. |
| Quick filter | Shows one filter as large buttons above the products. Enter its name as it appears in your filters, for example `Product type`. |
| Enable sorting | Shows the sort menu: featured, best selling, alphabetical, price and date. |

The cards follow the [Product cards](theme-settings.md#product-cards) theme settings. When visitors open a product from a collection, the product page breadcrumbs lead back to that collection.

### Filters

Filters are managed in the free **Shopify Search & Discovery** app, under **Filters**. You can filter by availability, price, product type, vendor, tags, variant options such as color and size, and metafields.

Color filters show swatches when your color option uses the Color category metafield. See [Color swatches](product-page.md#color-swatches).

### Pagination

| Option | How it works |
| --- | --- |
| Page numbers | Numbered pages at the bottom of the grid. |
| Load more button | Visitors press a button to add the next products to the grid. |
| Infinite scroll | The next products load on their own as visitors reach the end of the grid, up to 4 times in a row. Then a button loads the rest, so visitors can still reach the footer. |

Filters and sorting update the page address, so visitors can bookmark or share a filtered view, and the back button returns to the previous filters.

## Collections page

The page that lists all your collections, at `/collections`. Edit it from **Collections list** in the theme editor's page selector.

| Setting | What it does |
| --- | --- |
| Heading | The title of the page. |
| Collections per page | 6 to 48. |
| Columns on desktop | 2 to 4. |
| Image ratio | Square, Portrait or Landscape. |
| Card style | Text over image, or Text below image. |

## Search

### Search suggestions

When **Enable search suggestions** is on in **Theme settings > Search**, results appear as visitors type: products, collections, pages and articles. See [Search settings](theme-settings.md#search).

### Search results page

Shows the matching products, articles and pages. Products can be filtered and sorted like a collection.

| Setting | What it does |
| --- | --- |
| Results per page | 8 to 48. |
| Columns on desktop | 2 to 5. |
| Enable filtering | Shows the filters set in the Search & Discovery app. |
| Enable sorting | Shows the sort menu. |
