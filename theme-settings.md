# Theme settings
{: .no_toc }

Theme settings apply to the whole store. In the theme editor, choose the paint brush icon to open them.

1. TOC
{:toc}

## Logo

| Setting | What it does |
| --- | --- |
| Logo | Shown in the header. Without a logo, the store name shows as text. |
| Desktop logo width | 50 to 300 px. |
| Mobile logo width | 40 to 200 px. |
| Favicon image | The small icon in browser tabs. Use a 32 x 32 px PNG. |

## Colors

Sinew uses **color schemes**: named sets of colors that every section can use. The theme comes with five schemes, and you can add more. Each section has a **Color scheme** setting, so changing a scheme updates every section that uses it.

| Color | Where it shows |
| --- | --- |
| Background | Section background. |
| Background gradient | Replaces the background color when set. |
| Text | Headings and body text. |
| Accent | Highlights, such as the diagonal fill of buttons and active states. |
| Text on accent | Text shown on top of the accent color. |
| Button background | Solid buttons. |
| Button label | Text of solid buttons. |
| Outline button | Border and text of outline buttons. |
| Borders | Dividers, input borders and card outlines. |

{: .tip }
Keep enough contrast between text and background, and between buttons and their labels, so every visitor can read them. A free contrast checker, such as the one from WebAIM, tells you whether two colors pass.

## Typography

| Setting | What it does |
| --- | --- |
| Headings: Font | The heading font, from Shopify's font library. |
| Headings: Font size scale | 80 to 150 %. Scales every heading together. |
| Headings: Letter case | Default or Uppercase. |
| Body text: Font | The font of paragraphs, prices, buttons and forms. |
| Body text: Font size scale | 90 to 130 %. |

## Layout

| Setting | What it does |
| --- | --- |
| Page width | Narrow or Wide: the maximum width of page content. |
| Page margin | 10 to 100 px of space at the left and right edges of the screen. |
| Show back-to-top button | Shows a button in the bottom corner after visitors scroll down, to return to the top of the page. It moves above the sticky add to cart bar when both show. |

## Buttons

| Setting | What it does |
| --- | --- |
| Corner radius | 0 to 40 px. 0 gives square corners. |
| Border thickness | 1 to 3 px. |
| Letter case | Default or Uppercase. |
| Hover effect | **Diagonal fill** fills the button with the color scheme's accent color. **Lift** raises the button slightly. **Color change** changes the colors only. With reduced motion turned on in the visitor's device, buttons change color without movement. |

## Inputs

Corner radius (0 to 10 px) and border thickness (1 to 3 px) of form fields, such as search, newsletter and contact fields.

## Product cards

These settings apply to every product card in the store: collections, search, featured products and recommendations.

| Setting | What it does |
| --- | --- |
| Image ratio | Adapt to image, Square, Portrait or Landscape. |
| Image fit | **Fill** crops the photo to the frame. **Fit** shows the whole product, centered on a soft background. Fit works best with photos on a white or transparent background. |
| Image background | Shown behind the product when Image fit is Fit. Pick the color of your photo backgrounds, for example white, so they blend in. |
| Text alignment | Left or Center. |
| Card style | **Editorial** adds space under the image and shows the title in uppercase, with the price below it. |
| Title font | Body or Heading font. |
| Title size | Small, Medium or Large. |
| Show second image on hover | Shows the product's second photo when visitors point at the card. |
| Show vendor | Shows the product vendor above the title. |
| Show product rating | Shows the star rating from your review app. See [Product rating](product-page.md#product-rating). |
| Show quick add button | Products with one variant are added to the cart directly. Products with options show their choices on the card, for example color and size. Products with more than 100 variants open the product page. |
| Show color swatches | Shows the colors of the product. See [Color swatches](product-page.md#color-swatches). |
| Show available sizes | Lists the sizes, with sold out sizes crossed out. |
| Size option names | The names of your size options, separated by commas, for example `Size, Talla, Taille`. |

## Badges

| Setting | What it does |
| --- | --- |
| Position | Top left, Top right or Bottom left of the product image. |
| Sale badge | **Sale** or **Discount percentage**. The percentage comes from the compare-at price: "-22%", or "Up to -22%" when variants have different discounts. |
| Sale badge background and text | Colors of the sale badge. |
| Sold out badge color scheme | Colors of the sold out badge. |

## Animations

| Setting | What it does |
| --- | --- |
| Reveal sections on scroll | Sections fade in as they come into view. |
| Hover effect | None, Subtle or Lift: the effect on cards and images when visitors point at them. |
| Enable page transitions | Fades between pages, and moves product images from the card to the product page in browsers that support it. |

All animations are off for visitors who turn on reduced motion in their device settings.

## Social media

Enter the full link of each account, for example `https://www.instagram.com/yourbrand`. Supported networks: Instagram, TikTok, YouTube, Facebook, X (Twitter), Threads, Pinterest, Snapchat, LinkedIn, Tumblr and Vimeo.

The icons show wherever you add a **Social media icons** block, usually in the footer. Networks without a link are hidden, and the block shows nothing until at least one link is set.

## Search

| Setting | What it does |
| --- | --- |
| Enable search suggestions | Shows products, collections, pages and articles as visitors type in the search field. |
| Show product vendor | Shows the vendor in the suggestions. |
| Show product price | Shows the price in the suggestions. |

## Currency format

**Show currency codes** adds the currency code to prices, for example $1.00 USD. Useful when you sell in several currencies that share a symbol. Prices in the cart and at checkout always show it.
